# Changelog

## 1.0.0 — First public release

- Background screen break scheduling with configurable interval and duration.
- Static desktop blur, monochrome grain, red radial haze and custom center text.
- Settings window, unsaved preview, validation and atomic JSON persistence.
- Tray menu, manual rest, one-hour pause, resume and Esc dismissal.
- User Startup shortcut and single-instance protection.
- Self-contained Windows x64 package, MIT license and Windows build workflow.

Earlier local development labels were not public releases. This is the first public
semantic version. See the GitHub Release for the actual publication date.
