# Security policy

Security fixes target the latest public release. Use the latest available version.

If GitHub's **Security → Report a vulnerability** button is available, use it for
private reporting. Include reproduction steps, affected version and impact.
Do not include personal desktop content or credentials.

If that button is unavailable, there is no verified private reporting channel.
Open an issue requesting a private contact without exploit details, credentials,
or sensitive files; wait for a private channel before disclosing technical details.

EyeCarer captures the desktop in memory to render its static break overlay. See the
README privacy section. Do not publish actual desktop captures as bug reports.
